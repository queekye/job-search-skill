# 卓驭公开 JD 读取

观察日期：2026-10-16。范围为公开目录和一个可见完整详情表面；其他目录、下架和登录后页面需要现场核对。本文件为操作说明，没有网页执行代码。

## 入口与身份

- 官方首页 `https://we.zyt.com/` 展示校园招聘 `/campus/jobs`、领航者计划 `/5/jobs` 和社会招聘 `/social/jobs`。
- 本轮由公开目录的“查看详情”观察到 `/5/detail?jobAdId=<官方岗位ID>`。该路由也能显示标为“校园招聘 全职”的岗位，不能只按路径中的 `5` 推断招聘项目。
- 先用已有 `job_id` 打开精确详情，核对实际 URL 的 `jobAdId`、完整标题、城市和页面标示项目。同名或职责相近而 ID 不同的岗位保留为 `related`，不替换原岗位身份；岗位改名也须明确保留原记录。

## 完整读取

列表点击岗位可展开“工作职责”“任职资格”，再用“查看详情”进入详情页（可能新开标签）。详情有标题、招聘类型、全职/实习、城市、发布日期及两个正文区；完整保留正文中的编号、加分条件和限制。目录混有实习，读取已有岗位并不授权扩展实习推荐。

网页初次只显示页头时继续确认加载后的正文，不能把加载空白当成无岗位。由服务保存 `job_description/jd_url/jd_checked_at/jd_coverage/jd_identity_status`，JD 观察与申请进度独立。

## 边界

本轮公共 JD 无需登录；“立即投递”“收藏”不是读取操作，不点击。登录后的个人中心或投递记录、下架详情及历史投递快照尚未验证。若精确链接只显示登录、异常或无正文，记录实际尝试时间与阻点，保留最后成功 JD；需要本人登录时打开官方入口供本人操作。不能把回源失败或公开停止招聘解释成已有申请结束。
