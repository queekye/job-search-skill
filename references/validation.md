# 验证

源码测试只使用合成记录和仓库外临时目录，不读取真实档案、消息来源或招聘账户。

## 可重复检查

```powershell
.\Check.cmd
python scripts/check_node.py
python scripts/check_source.py
python scripts/build_release.py
python scripts/verify_release.py dist/marketplace
```

`Check.cmd` 覆盖数据库账号/任务、修改版本与恢复、资料导入、HTTP/MCP、OTP、资源包及发行校验；Node 测试覆盖公司页面解析、限定控件和网页异步行为。原生启动器测试核验 Codex Python 默认探测、独立数据目录及八工具握手，精简运行包从解压后的带空格路径启动。

源码检查按明确允许清单扫描公开源文件、文档与合成测试；发行构建另扫描运行文件和归档所用快照，输出运行 ZIP、公司包、静态目录、文件哈希与安装清单。可用 `--private-patterns-file` 传入仓库外私有字符串数组，扫描仅在本机运行且不打印匹配值。规则扫描需要人工内容审阅；安装清单核验保证文件一致，不认证发布者或替代运行验收。

## 换机接续

在仓库外合成目录实际执行公开 PowerShell 备份、恢复入口，覆盖多账号、超过单页的记录、SQLite WAL 中已提交修改、归档资料、附件哈希、导入身份、设置与任务历史、已接受与待审资源。新目录应保留原 ID、原始官网状态和成功核验时间；按 ID 解析的附件路径应指向新目录。运行任务转待继续需新 revision 和历史事件；已有完成/取消状态保持，宿主绑定和取码窗口在新副本清除。验证导入身份继续幂等、账号隔离、跨机令牌不冒充可用及旧连接测试不冒充通过。

损坏成员、越界路径、缺失附件、不支持的数据库版本和非空目标必须在安装前拒绝，并保留原目录与备份。ZIP 完整性不认证来源；恢复本人保管的私有备份。浏览器登录和外部自动化在新电脑重新连接，不计入文件迁移成功。

## 公司泛化

合成矩阵应覆盖：不同学校和学历、可变教育/项目/论文数量、同学历多条经历、旧键兼容、非空冲突、重复身份、中途结构变化、不同租户授权及字段读回。检查新增支持的路径和剩余未知结构；没有真实页面证据时不猜新增、删除、保存行为。文档型资源仍明确没有执行能力。

公司版本不可变，内容或许可变化使用新版本和成员哈希。历史页面证据属于原观察范围；新版本合成通过不能自动获得现场或安装后通过状态。实际用户值、DOM、截图、短信和令牌只留私有验收目录。

## 个人同步与公共目录

WebDAV 使用 localhost 条件请求服务和两份独立合成数据，覆盖全账号与附件、单写者交接、自动上传/拉取、冲突与损坏拒绝、远端保留、跨进程门禁、目录替换中断恢复和停用后重新启用。实际网页验收使用真实本地服务、Windows DPAPI 和独立浏览器上下文，确认换机后资料、任务与附件路径，以及轮询期间未保存的输入。

检查云快照成员只有个人数据库、原始附件和清单；公司资源、待审包、锁、OTP 与 WebDAV 凭据不进入快照。各机公共资源和验证码配置在拉取后保持原样。静态目录另用真实本地 HTTP 验证索引、固定版本下载、完整审阅和本人批准；发行目录的每个 ZIP 必须与索引的字节数、SHA-256 和单独公司包完全一致。

以上不证明某个真实 WebDAV 服务支持强 ETag 与条件更新，也不证明已部署 GitHub Pages 或 Cloudflare Pages。真实存储接入和公开托管须分别验收，不能由 localhost 测试替代。

## 验收分层

| 层次 | 验证内容 |
| --- | --- |
| 源码 | Python/Node 合成行为与失败边界 |
| 本地网页 | 新账号读写、社招偏好保留、推荐/申请分离、材料、历史与任务 |
| 运行发行 | ZIP完整性、许可与成员、干净解压、启动及MCP八工具 |
| 原生安装 | 隔离Codex配置安装市场、工具路径与实际调用 |
| 真实网站 | 每家公司当前控件、字段动作、官网保存刷新与具体覆盖 |

每次报告各层实际结果与未运行项，不将历史原生安装、源码调用或同值核验升级为当前版本整站通过。最终岗位选择、资料审阅与投递由用户执行；日常插件、自动化和真实数据不作为开发测试环境。

## 能力目录与面试准备验收

使用仓库外合成数据库，验证公共目录的 HTTP/MCP 同源、参数与输出完整性、显式账号隔离、来源修订变化、缺失与归档引用、旧任务取消及未知字段保留。`scripts/career-call.py` 实测 stdio 初始化、工具拒绝和显式账号；不存在的数据库目录应拒绝而不另建档案。

网页从任务区创建面试任务，关联合成申请与研究，修改摘要并保存读回；对照旧来源修订、计划、讲述卡和具体误区，确认未复测不显示已掌握。旧任务缺少来源 pin 时不能默认为当前版本；未知 schema 或字段结构回退 JSON，不静默改写。源码/DOM 合成测试与实际浏览器结果分开，不使用真实申请记录作夹具。

安装只针对本项目的审阅运行快照，核对文件清单后在新 Codex 会话验证四个 skills 与八组原生工具，以及 capability.list/describe、interview.schema 和受限 record.list 查询。源码 CLI 能调用不代表原生工具已加载；安装器返回成功也不代表新会话验收通过。原有招聘插件的启用状态与版本、既有自动化文件哈希在安装前后对比。真实招聘网站不属于本次新增能力的验收范围。
